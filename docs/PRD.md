## 1. 产品概述与定位

### 1.1 一句话定位（Slogan）

> **让死在 PDF 里的论文公式与科学机理，在浏览器里瞬间“活”起来。**

### 1.2 背景与目标

科研人员（硕博生、交叉学科研究者）日常面临“公式难建直觉、假设验证环境配置繁琐、组会动态演示制作成本极高”三大痛点；而市面上现有的 AI 科研工具大多局限于“对话式文字总结”，无法提供直观的动态交互体验。

**SciCanvas** 是一款基于 **Generative UI（生成式交互界面）** 的浏览器端零配置科研仿真沙盒。用户输入论文公式、机理描述（或上传文献公式/示意图截图），AI 即可在前端即时构建出**可调节参数、可单步推演、可实时监测数据、可一键用于组会投屏演示**的实时交互实验画布。

### 1.3 目标用户画像

- 
- **核心用户**：理工科/交叉学科硕博研究生、科研人员（高频读顶会论文、做前置推演、讲组会）。
- **次级用户**：高校理科/工科教师及助教（需要快速制作课堂动态演示模型）。
- **评审视角用户（关键！）**：黑客松评委（无专业科研背景前置准备，需要**打开链接 3 秒内看懂亮点，零登录直接把玩**）。

## 2. 痛点与价值闭环













| 科研真实痛点              | 传统解决方式及缺陷                                           | SciCanvas 解决方案                                           |
| ------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **公式与静态图太抽象**    | 盯着 PDF 死记或问 ChatGPT（依旧只输出文字），看不出参数敏感性。 | **“公式 → 实时沙盒”**：自动提取关键变量生成滑动条，拖动滑块实时观测非线性相变与边界效应。 |

## 4. 功能详细需求（Functional Requirements）

### 模块 F1：零门槛预设科研案例库（Preset Lab Library）【P0 - 必做】

- 
- **需求描述**：页面首屏及左上角提供 4 个跨学科、高视觉冲击力的内置预设实验，确保无需调 API 也能 100% 稳定运行，供评委和用户秒级体验。
- **预设清单设计**：**AI / 优化理论**：*多优化器地形逃逸对比（SGD vs Momentum vs Adam）*——3D/等高线损失曲面，小球滚落动态，直观展示鞍点卡顿与震荡。**物理 / 工程**：*受迫阻尼振动与共振相空间*——左侧展示弹簧振子实时运动，右侧同步绘制“位移-速度”相图（Phase Portrait），拖动驱动频率触发共振爆炸现象。**生物 / 复杂系统**：*传染病 SIR 模型与群体免疫阈值相变*——粒子碰撞传染模拟 + 实时人群占比折线图，调节 `R0R0` 观察系统跨越阈值的突变。**信号处理 / 数学**：*傅里叶级数方波合成与吉布斯现象（Gibbs Phenomenon）*——拖动谐波叠加项数 `NN`，观察矩形波逼近过程与边缘过冲现象。

### 模块 F2：AI 实验生成与多模态微调引擎【P0 - 必做 / 截图为 P1】

- 
- **文本 / 公式输入 [P0]**：支持自然语言描述（如：“生成一个带有衰减因子的二维波动干涉实验”）或直接粘贴 LaTeX 论文公式。
- **论文图片识别（Multimodal）[P1]**：支持粘贴/上传一张论文公式截图或机理示意图（调用多模态大模型 Vision API），自动识别变量关系并生成仿真沙盒。
- **增量微调（Iterative Refinement）[P0]**：在已生成的实验基础上，输入追问指令（例如：*“把背景地形改成非凸的双峰函数”、“增加一个高斯白噪声滑动条”*），AI 结合当前实验上下文进行增量代码更新，而非从头推翻重来。
- **快捷灵感标签**：输入框下方提供 3 个一键追问胶囊（如 + 加入随机噪声、+ 对比基准模型、+ 高亮梯度向量）。

### 模块 F3：安全沙盒渲染与代码自愈引擎（Core Engine）【P0 - 必做】

- 
- **需求描述**：核心痛点在于“LLM 生成的前端绘图代码可能出现语法错误或运行时崩溃”。本模块必须保证系统高可用。
- **实现机制**：**严格隔离的渲染环境**：使用独立 <iframe sandbox="allow-scripts"> 或受控 Function 沙盒执行 AI 生成的仿真逻辑，防止污染主应用状态或引发安全问题。**标准生命周期接口协议**：规定 AI 生成代码必须暴露统一的生命周期钩子（init(ctx, params), step(state, params, dt), draw(ctx, state, params), getTelemetry(state)）。**运行时错误自动捕获与自愈（Auto-Heal）[P0 亮点]**：主控台监听沙盒内的 onerror 和异常堆栈。一旦 AI 生成的代码在初始化或第 1 帧报错，前端界面显示“正在自动修复模型数学逻辑...”，同时将报错信息静音回传给 LLM 进行自动修正并重载（最多自动重试 2 次）。

### 模块 F4：动态参数控件、边界预设与遥测联动【P0 / 探针为 P1】

- 
- **动态控件面板 [P0]**：根据 AI 返回的 JSON Schema，自动渲染滑动条（Slider，带精确数值与物理单位）、开关（Switch）、下拉选择（Select）。
- **极端边界态快捷按钮（Corner Cases）[P1]**：每个实验由 AI 额外生成 2～3 个“有科研洞察力的参数预设组合”（如：理想无阻尼、临界阻尼、系统发散/崩溃），点击一键把所有滑块拨到对应位置，帮助用户秒懂系统极限行为。
- **时间控制条 [P0]**：支持 播放/暂停、单步步进（Step Forward，每点一次推进 1 帧/1 轮迭代）、倍速控制（0.5x / 1x / 2x）、重置初始态。
- **实时遥测微图表（Telemetry）[P1]**：画布右下角挂载一个半透明浮层小图表（ECharts 或轻量 Canvas 折线图），实时绘制随时间演化的核心指标（如 Total Energy、Loss、I(t) 感染率等）。
- **鼠标探针（Hover Probe）[P1]**：鼠标移入画布任意位置时，在指针旁显示实时坐标与局部物理量/函数值 Tooltip。

### 模块 F5：极简组会演示模式与单文件导出【P1 - 夺奖核心亮点】

- 
- **一键演示模式（Presentation Mode）**：点击右上角 [进入组会演示模式]，界面丝滑收起左侧输入栏和历史记录，仅保留全屏画布 + 底部参数控制条 + 角落 KaTeX 公式浮窗，适配学术报告投影场景。
- **导出独立可交互 HTML（Export Standalone HTML）**：前端将当前的实验逻辑代码、参数 Schema、基础渲染壳与 KaTeX 样式直接拼接打包为一个 .html 文件下载到本地。科研人员可直接将该文件发给导师或附在个人主页上，**对方双击即可在离线浏览器里交互操作，无需部署服务器**。

### 模块 F6：本地科研工作区（Local Workspace）【P1】

- 
- 使用浏览器 IndexedDB（如封装 Dexie.js 或原生）自动保存用户生成过的实验记录、代码版本及最近参数状态。支持重命名、收藏、快速切换和删除，无需后端数据库。

## 5. 技术架构与核心协议设计

### 5.1 前端技术栈选型

- 
- **核心框架**：React 18+ / Next.js（或 Vite + React）+ TypeScript
- **样式与组件库**：Tailwind CSS + Shadcn UI（构建冷峻专业的极简科研面板）
- **图形与可视化引擎**：2D 物理/数学/粒子仿真：HTML5 Canvas API / SVG3D 曲面/空间轨迹仿真：Three.js（或 React Three Fiber）实时数据折线图表：ECharts（轻量引入折线/散点模块）或自定义高性能 Canvas Sparkline
- **数学公式排版**：KaTeX（渲染速度快于 MathJax，支持行内/块级公式）
- **图标库**：Lucide React
- **大模型接入方案**：通过轻量化 Serverless Edge Function（如 Vercel Edge / Next.js API Route）转发大模型请求；前端设置“内置限时体验额度（用于评委无门槛测试） + 支持用户填写自有 API Key（存于本地 localStorage）”。

## 6. 非功能性需求与视觉规范

1. 
2. **审美与字体规范（决定 20% 交互与审美分）**：背景色采用深邃科研灰蓝（如 #0B0F17 画布底色 + #111827 侧边栏 + 1px solid rgba(255,255,255,0.08) 微弱分割线），高亮色选用高对比度科研蓝/青（#38BDF8）和警示琥珀色（#F59E0B）。**数值必须使用等宽字体（tabular-nums / JetBrains Mono）**，防止拖动滑块时数字跳动引起视觉抖动。画布底层绘制极淡的坐标网格线（类似工程制图纸/示波器），提升专业感。
3. **性能与稳定性**：画布需支持 window.devicePixelRatio 高清屏适配（Retina 不模糊）。动画循环严格使用 requestAnimationFrame 并做帧率时间差限制（防止切后台回来 dt 过大导致物理仿真飞出屏幕）。
4. **容错兜底**：当 API 超时或网络异常时，友好提示并保持当前画布可用，不影响内置预设案例的把玩。
