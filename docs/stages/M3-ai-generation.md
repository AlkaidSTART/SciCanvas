# M3｜AI 实验生成 MVP

**用户价值：**用自然语言或粘贴的 LaTeX 描述一个科学问题，获得可操作的实验画布。

**阶段状态：**待开始  
**依赖：**M1；复用 M2 的工作台案例体验（M2 可与 M3 并行，但正式集成应使用统一 Schema）。  
**PRD 来源：**F2 文本/公式输入、F3 运行时协议、5.1 大模型代理方案、5.2 Generative UI Schema。

## MVP 边界

实现文本或 LaTeX 到结构化实验 Schema，再到画布运行的单次生成流程。模型生成的是 Schema 与受控仿真逻辑，不生成任意页面 HTML。论文图片识别留到 M8；基于已有实验的增量微调留到 M4。

## 交付任务

- [ ] **M3.1 输入与请求状态**：提供自然语言/LaTeX 输入、提交、取消（若接口支持）、生成中和失败状态。
- [ ] **M3.2 模型服务代理**：从服务端函数/API 路由转发请求；服务端凭证只存在服务端；加入超时、错误映射和必要的请求限制。
- [ ] **M3.3 结构化生成协议**：要求模型按 M1 Schema 返回 JSON；用服务端和客户端校验，不接受未经校验的模型输出。
- [ ] **M3.4 安全运行生成结果**：将验证后的仿真逻辑接入隔离运行时；明确哪些浏览器能力不可访问，限制生成脚本对主应用状态的影响。
- [ ] **M3.5 生成结果预览与应用**：成功后显示实验标题、公式、说明和控件；失败或拒绝结果时保留当前可用实验，并提供预设回退入口。
- [ ] **M3.6 服务故障兜底**：对网络失败、超时、限额、无效 JSON、Schema 不合法等情况给出可理解提示。
- [ ] **M3.7 流程验证**：覆盖有效输出、无效输出、超时和仿真初始化失败；确认无服务端密钥泄露。

## 验收标准

- [ ] 可提交自然语言和 LaTeX 请求，并收到一个符合 Schema 的可交互实验。
- [ ] 模型输出必须经过类型、范围和必需字段校验后才能运行。
- [ ] 模型或网络不可用时，失败有明确反馈；已有实验和内置预设仍可使用。
- [ ] 服务端凭证不出现在浏览器 bundle、请求响应、localStorage 或 IndexedDB 中。
- [ ] 生成仿真运行在隔离上下文中，不能直接改写主应用 DOM 或 React 状态。
- [ ] 测试覆盖主要失败分支；lint/build 通过。

## 完成定义

从用户提交描述到实验展示、参数操作以及失败回退的闭环可重复演示。

## 暂不纳入

多模态截图输入（M8）、增量修改（M4）、生成代码自动修复（M4）；用户自有 API Key 与第三方 API 站点端点的配置界面及存储归入 M7（已定选型为 IndexedDB）。
