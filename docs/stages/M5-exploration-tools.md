# M5｜科学探索增强 MVP

**用户价值：**通过边界案例、实时指标和局部探针观察模型演化，不只依赖最终画面。

**阶段状态：**已完成  
**依赖：**M1、M2；AI 生成实验支持这些可选能力需在 M3 后接入。  
**PRD 来源：**F4 边界态快捷按钮、实时遥测和 Hover Probe。

## MVP 边界

将探索辅助能力接入已有预设实验：通过边界态快速切换参数组合，在画布上查看随时间更新的指标，并在悬停时查看局部值。四个预设均声明边界态；阻尼振动、SIR 与优化器提供遥测，SIR、傅里叶与优化器提供探针。阻尼振动与傅里叶对未声明的能力明确降级（不渲染空图表或空数值）。

## 交付任务

- [x] **M5.1 Schema 扩展**：定义边界案例、遥测序列及探针回调/坐标映射契约，并对缺省能力提供可选语义。
- [x] **M5.2 边界态控件**：显示实验声明的 2–3 个快捷参数组合；点击后原子更新所有相关参数并重置/继续仿真状态（按实验语义约定）。
- [x] **M5.3 实时遥测浮层**：绘制有限长度的轻量折线历史，展示指标名、当前值和单位；暂停时冻结采样，重置时清空或按契约重新开始。
- [x] **M5.4 Hover Probe**：按设备像素比与画布坐标变换计算指针位置；展示坐标和模型返回的局部值；触屏/不支持场景可隐藏或降级。
- [x] **M5.5 性能与覆盖验证**：限制遥测缓存长度；验证高频动画下控制交互流畅；为各支持预设定义指标含义。

## 验收标准

- [x] 支持边界态的实验可一键切换，控件显示值与实际参数一致。
- [x] 支持遥测的实验在运行时更新曲线，暂停后曲线不继续增长，重置行为一致。
- [x] 支持探针的实验显示有效坐标/局部值；移出画布后关闭提示。
- [x] 能力未声明或不适用时不显示误导性的空图表/数值。
- [x] 遥测数据有界，不因长时间运行无限增长；调整窗口和高 DPR 时仍正确绘制。
- [x] 支持能力的预设均有可重复验收步骤，lint/build 通过。

## 能力覆盖与验收步骤

| 预设 | 边界态 | 遥测 | 探针 |
| --- | --- | --- | --- |
| 阻尼受迫振动 | 低阻尼共振 / 过阻尼收敛 / 自由衰减 | 机械能 E、位移 x、驱动力 F | 未声明（降级） |
| SIR 传播 | 亚临界 R₀<1 / 典型 R₀=3 / 超级传播 R₀=6 | 感染占比 I、有效传播数 Rₑ | 曲线时刻 → 感染占比 |
| 优化器地形 | 小步长探索 / 峡谷高动量 / 大步长震荡 | 三种优化器损失 | 地形任意点 → 损失与梯度强度 |
| 傅里叶方波 | N=1 / N=9 / N=41 | 未声明（降级） | 相位 → 部分和取值 |

手动验收：

1. 任一预设点击边界态，观察滑块/开关/下拉值与 chip 选中态同步，仿真从初始状态继续。
2. 有遥测的预设运行数秒后暂停，确认点数与曲线不再增长；重置后点数回到 1 且数值为初值。
3. 有探针的预设悬停画布绘图区，确认浮层显示坐标与局部值；移出画布后浮层消失。
4. 切换到未声明能力的预设，确认对应浮层与快捷态整行不出现。

## 完成定义

至少两个预设具备完整、科学含义明确的边界案例、遥测和/或探针体验，并对其他案例做到明确且不误导的能力降级。

## 暂不纳入

复杂统计分析、数据导出、AI 生成任意遥测插件；后续可在核心契约稳定后扩展。
