# M5｜科学探索增强 MVP

**用户价值：**通过边界案例、实时指标和局部探针观察模型演化，不只依赖最终画面。

**阶段状态：**待开始  
**依赖：**M1、M2；AI 生成实验支持这些可选能力需在 M3 后接入。  
**PRD 来源：**F4 边界态快捷按钮、实时遥测和 Hover Probe。

## MVP 边界

将探索辅助能力接入已有预设实验：通过边界态快速切换参数组合，在画布上查看随时间更新的指标，并在悬停时查看局部值。MVP 可先让四个预设中的至少两个提供有意义的遥测/探针，其余案例对不适用能力明确降级；随后可扩展覆盖。

## 交付任务

- [ ] **M5.1 Schema 扩展**：定义边界案例、遥测序列及探针回调/坐标映射契约，并对缺省能力提供可选语义。
- [ ] **M5.2 边界态控件**：显示实验声明的 2–3 个快捷参数组合；点击后原子更新所有相关参数并重置/继续仿真状态（按实验语义约定）。
- [ ] **M5.3 实时遥测浮层**：绘制有限长度的轻量折线历史，展示指标名、当前值和单位；暂停时冻结采样，重置时清空或按契约重新开始。
- [ ] **M5.4 Hover Probe**：按设备像素比与画布坐标变换计算指针位置；展示坐标和模型返回的局部值；触屏/不支持场景可隐藏或降级。
- [ ] **M5.5 性能与覆盖验证**：限制遥测缓存长度；验证高频动画下控制交互流畅；为各支持预设定义指标含义。

## 验收标准

- [ ] 支持边界态的实验可一键切换，控件显示值与实际参数一致。
- [ ] 支持遥测的实验在运行时更新曲线，暂停后曲线不继续增长，重置行为一致。
- [ ] 支持探针的实验显示有效坐标/局部值；移出画布后关闭提示。
- [ ] 能力未声明或不适用时不显示误导性的空图表/数值。
- [ ] 遥测数据有界，不因长时间运行无限增长；调整窗口和高 DPR 时仍正确绘制。
- [ ] 支持能力的预设均有可重复验收步骤，lint/build 通过。

## 完成定义

至少两个预设具备完整、科学含义明确的边界案例、遥测和/或探针体验，并对其他案例做到明确且不误导的能力降级。

## 暂不纳入

复杂统计分析、数据导出、AI 生成任意遥测插件；后续可在核心契约稳定后扩展。
