# M8｜论文截图生成实验 MVP

**用户价值：**从论文公式或机理图截图开始创建实验，减少手动转录步骤。

**阶段状态：**待开始  
**依赖：**M3 的文本生成和 Schema 校验流程。  
**PRD 来源：**F2 论文图片识别（Multimodal）。

## MVP 边界

支持选择或粘贴一张图片，通过多模态模型提取公式、变量及关系，并将识别内容交给 M3 的实验生成流程。识别结果须先向用户展示并允许编辑/确认；不尝试自动理解整篇论文或保证科学结论正确。

## 交付任务

- [ ] **M8.1 图片输入交互**：支持单图粘贴与文件选择，显示预览、替换和移除；校验格式及合理的文件大小。
- [ ] **M8.2 多模态服务代理**：通过服务端代理上传/转发图片；保护服务端凭证，限制不支持的格式和异常请求。
- [ ] **M8.3 结构化识别**：提取可读公式、变量符号、文字说明和不确定项；保留识别置信提示或需要用户确认的字段。
- [ ] **M8.4 用户确认与编辑**：进入实验生成前展示识别文本/公式；允许修正内容或取消。
- [ ] **M8.5 复用 M3 生成流程**：将确认后的识别内容作为文本/公式请求调用 M3，不复制另一套生成和校验逻辑。
- [ ] **M8.6 失败和隐私反馈**：识别失败、模型不可用、图片过大时保留当前实验并给出清晰反馈；告知图片会被发送给配置的模型服务。

## 验收标准

- [ ] 可粘贴或上传单张受支持图片并查看预览。
- [ ] 识别出的公式/机理描述可以在生成前编辑和确认。
- [ ] 确认后进入 M3 的生成/Schema 校验/沙盒运行链路。
- [ ] 取消、识别失败或生成失败均不覆盖当前可用实验。
- [ ] 不支持的文件类型、过大图片和网络错误有可理解提示。
- [ ] 服务凭证不会暴露在浏览器；图片处理与第三方发送行为有明确告知。

## 完成定义

用户可以从单张论文截图出发，检查并修正识别内容，最终得到一个由 M3 正常校验和运行的交互实验。

## 暂不纳入

整篇 PDF 解析、文献搜索、自动引用管理、无人工确认的科学结论生成。
