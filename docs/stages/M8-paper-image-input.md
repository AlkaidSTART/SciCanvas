# M8｜论文截图生成实验 MVP

**用户价值：**从论文公式或机理图截图开始创建实验，减少手动转录步骤。

**阶段状态：**已完成（2026-11-25）  
**依赖：**M3 的文本生成和 Schema 校验流程。  
**PRD 来源：**F2 论文图片识别（Multimodal）。

## MVP 边界

支持选择或粘贴一张图片，通过多模态模型提取公式、变量及关系，并将识别内容交给 M3 的实验生成流程。识别结果须先向用户展示并允许编辑/确认；不尝试自动理解整篇论文或保证科学结论正确。

## 交付任务

- [x] **M8.1 图片输入交互**：支持单图粘贴与文件选择，显示预览、替换和移除；校验格式及合理的文件大小。
- [x] **M8.2 多模态服务代理**：通过服务端代理上传/转发图片；保护服务端凭证，限制不支持的格式和异常请求。
- [x] **M8.3 结构化识别**：提取可读公式、变量符号、文字说明和不确定项；保留识别置信提示或需要用户确认的字段。
- [x] **M8.4 用户确认与编辑**：进入实验生成前展示识别文本/公式；允许修正内容或取消。
- [x] **M8.5 复用 M3 生成流程**：将确认后的识别内容作为文本/公式请求调用 M3，不复制另一套生成和校验逻辑。
- [x] **M8.6 失败和隐私反馈**：识别失败、模型不可用、图片过大时保留当前实验并给出清晰反馈；告知图片会被发送给配置的模型服务。

## 验收标准

- [x] 可粘贴或上传单张受支持图片并查看预览。
- [x] 识别出的公式/机理描述可以在生成前编辑和确认。
- [x] 确认后进入 M3 的生成/Schema 校验/沙盒运行链路。
- [x] 取消、识别失败或生成失败均不覆盖当前可用实验。
- [x] 不支持的文件类型、过大图片和网络错误有可理解提示。
- [x] 服务凭证不会暴露在浏览器；图片处理与第三方发送行为有明确告知。

## 完成定义

用户可以从单张论文截图出发，检查并修正识别内容，最终得到一个由 M3 正常校验和运行的交互实验。

**行为说明**

- 支持 PNG / JPEG / WebP 单张图片，原始大小上限 4 MB；客户端在读取前按文件元信息拦截，服务端再次校验 data URL 与解码大小，超过上限返回 413 `image_too_large`。
- 识别请求只携带图片 data URL；服务端使用 `AI_VISION_MODEL`（缺省回退 `AI_MODEL`）以 `image_url` 内容块转发，凭证只出现在发往上游的请求头中，响应与页面不会包含凭证或原始图片。
- 识别结果包含 `formulaLatex`、`description`、`variables`、`uncertain` 与 `confidence`，经客户端/服务端同一套字段校验后才展示；公式与机理说明可编辑，变量与不确定项用于提示需要人工确认的内容。
- 用户点击“确认并生成实验”后，把确认后的内容拼成文本请求，直接复用 M3 的 `/api/generate`、Schema 校验与隔离沙盒运行，不新增第二套生成逻辑。取消、识别失败或生成失败时均不修改当前实验。
- 图片只存在于当前组件内存，不写入 IndexedDB 或本地工作区；错过的截图可重新选择，生成成功后输入区自动清空。

**验证结果（2026-11-25）**

- 单元/集成测试：`pnpm test` 共 21 个测试文件、220 个用例全部通过。新增覆盖：
  - 图片校验：支持格式、data URL 解析、损坏内容、文件元信息与 4 MB 上限、大小格式化；
  - 识别协议：完整结果、可选字段、字段类型/数量越界、置信度范围、生成提示词拼装；
  - 客户端：识别代理请求体、非图片本地拦截、图片过大/限额映射、结果二次校验、网络失败；
  - 服务端：多模态消息与视觉模型选择、模型回退、分段内容响应、未配置凭证、非法/超限图片、上游 429/401/超时、非 JSON 与无效结构。
- 构建与静态检查：`pnpm lint`（0 warning / 0 error）、`pnpm build` 通过。
- 浏览器端到端实测（本地 mock OpenAI 兼容服务）：
  1. 上传 `/tmp/m8-paper.png` 后显示预览、文件名与 `PNG · 70 B` 信息；
  2. 点击“识别截图”后出现“确认识别内容”、置信度 84%、需要确认项，以及可编辑的公式与机理说明；
  3. 点击“确认并生成实验”后顶部显示“当前实验 逻辑斯蒂增长实验”，画布持续渲染，参数滑块可交互，识别卡片自动清空；
  4. 未配置凭证时 `/api/recognize` 返回 503 `not_configured`（自动化测试覆盖）。
- 依赖真实多模态模型凭证的联调未在本环境执行；配置 `.env` 后可按上述步骤用真实模型复现。
