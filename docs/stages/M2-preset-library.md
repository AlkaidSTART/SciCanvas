# M2｜跨学科预设实验库 MVP

**用户价值：**无需 AI 服务即可切换不同学科的实验，比较参数变化带来的现象。

**阶段状态：**待开始  
**依赖：**M1  
**PRD 来源：**F1 零门槛预设科研案例库。

## MVP 边界

在 M1 的工作台和统一仿真契约上，交付 PRD 指定的四个预设：优化器地形逃逸、受迫阻尼振动、SIR 传播、傅里叶级数与吉布斯现象。若 M1 基线采用阻尼振动，M2 负责完善该案例并增加其余三个。所有案例不依赖 AI 或外部服务。

## 交付任务

- [ ] **M2.1 案例清单与元数据**：为四个案例定义统一标题、学科、公式、说明、控件、默认参数和必要的视觉图例。
- [ ] **M2.2 优化器案例**：展示 SGD、Momentum、Adam 在代表性损失地形上的轨迹差异，并提供可解释的参数调节。
- [ ] **M2.3 阻尼共振案例**：展示受迫振子和相空间轨迹，调整驱动频率/阻尼等参数时可观察共振与阻尼差异。
- [ ] **M2.4 SIR 案例**：展示易感、感染、移除群体随时间变化，提供 R0 等关键参数控制。
- [ ] **M2.5 傅里叶案例**：调整谐波项数，观察方波逼近与吉布斯过冲。
- [ ] **M2.6 案例选择与状态切换**：在侧栏展示案例入口；切换时销毁旧运行态并按新案例默认参数初始化。
- [ ] **M2.7 预设回归验证**：为每个案例验证初始化、运行、参数调整、暂停和重置路径。

## 验收标准

- [ ] 页面提供四个可识别的案例入口，打开时默认案例立即可交互。
- [ ] 四个案例均可在无网络/无模型配置时运行。
- [ ] 每个案例的主要参数能改变其对应现象，公式和说明与展示内容一致。
- [ ] 快速连续切换案例不会残留旧动画、控件值或画布内容。
- [ ] 每个案例均支持 M1 定义的时间控制；异常只影响当前案例且能恢复。
- [ ] 所有案例均有自动化或可重复的验收步骤，lint/build 通过。

## 完成定义

四个预设均通过各自的可交互验收，并能通过同一个工作台入口稳定切换。

## 暂不纳入

AI 生成和微调（M3/M4）、边界态快捷组合与遥测/探针（M5）、本地保存（M7）。
