# M6｜组会展示与离线导出 MVP

**用户价值：**把交互实验用于组会/答辩投屏，并将实验文件分享给无需部署 SciCanvas 的其他人。

**阶段状态：**已完成（2026-11-25）
**依赖：**M1；导出 AI 生成实验需 M3 的 Schema/代码结果。  
**PRD 来源：**F5 演示模式、独立可交互 HTML 导出。

## MVP 边界

提供简洁的演示布局和单文件导出。导出包须包含实验所需的运行时、实验数据/代码、公式展示和交互控件，且离线可用。首个版本可优先支持内置预设；M3 完成后再保证 AI 实验导出。

## 交付任务

- [x] **M6.1 演示模式布局**：提供进入/退出控制；隐藏案例库、生成器和历史面板；保留画布、公式和必要的参数/时间控制。
- [x] **M6.2 演示状态体验**：支持键盘/指针可达的退出方式；窗口尺寸变化时画布自适应；不意外清除当前实验状态。
- [x] **M6.3 HTML 打包器**：将版本化运行时、Schema、实验逻辑和必要样式/公式渲染资源内联到单一 HTML；不依赖在线 CDN。
- [x] **M6.4 下载与文件命名**：根据实验标题生成安全文件名；下载完成后释放临时 Blob URL。
- [x] **M6.5 离线兼容验证**：断网双击导出文件，验证参数控制、时间控制、绘图、公式和错误提示。
- [x] **M6.6 导出失败反馈**：对不支持的渲染能力、资源过大或序列化失败给出明确原因，不影响当前实验。

## 验收标准

- [x] 演示模式可一键进入和退出，核心实验仍可播放和调参。
- [x] 导出结果是单个 HTML 文件，无相邻资源目录和网络依赖。
- [x] 断开网络后直接打开导出文件，实验仍可交互。
- [x] 文件名可读且处理非法字符；导出完成后不持续占用临时内存引用。
- [x] 不支持的实验能力有明确提示，不生成无法运行却看似成功的文件。
- [x] 至少覆盖内置预设离线导出；若包含 M3 实验，验证其逻辑正确导出。

## 完成定义

至少一个完整实验能够在演示模式中操作，并导出为可独立离线运行的单文件 HTML。

## 暂不纳入

在线分享/托管、协作编辑、视频录制与云端文件管理。
