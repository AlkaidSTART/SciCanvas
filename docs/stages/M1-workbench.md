# M1｜可交互科研画布 MVP

**用户价值：**打开 SciCanvas，无需登录或配置 API，即可直接观察并操作一个科学实验。

**阶段状态：**已完成（2026-11-25；视觉主题待统一）  
**依赖：**无  
**PRD 来源：**信息架构、F1 的免 API 预设原则、F3 核心运行时、F4 动态控件与时间控制、视觉与性能规范。

## MVP 边界

M1 建立可工作的端到端最小闭环：工作台显示一个默认实验；参数控件驱动仿真；用户可以播放、暂停、单步和重置。此阶段只需一个 Canvas 2D 实验作为运行时基线，建议采用阻尼振动。AI 生成、完整案例库、遥测图、论文截图和本地历史不属于 M1。

## 交付任务

- [x] **M1.1 统一实验数据契约**：定义 TypeScript Schema，覆盖标题、学科、公式、说明、渲染类型、控件、默认参数和仿真代码接口；增加运行时输入校验。
- [x] **M1.2 建立工作台骨架**：实现顶部栏、案例/生成侧栏占位、实验画布和底部控制区；采用 PRD 深色科研主题、等宽数值和适配窄屏的基础布局。当前暂为暖纸浅色主题，深色主题按用户决定延后统一切换。
- [x] **M1.3 建立 Canvas 仿真运行时**：支持初始化、按固定/受限时间步推进、绘制、暂停、恢复、单步和重置；处理 DPR、ResizeObserver、组件卸载及标签页切后台后的时间差。
- [x] **M1.4 提供一个内置基准实验**：实现一个完整、可操作的 Canvas 2D 示例，默认进入页面即加载；按 Schema 声明至少一个连续参数控件。
- [x] **M1.5 增加基础故障隔离**：捕获模型初始化和绘制异常，显示局部错误状态并提供重置/回到默认实验入口；不让画布错误破坏工作台其余区域。
- [x] **M1.6 补齐基础验证**：覆盖 Schema 校验、控件参数更新、时间控制和运行时卸载清理；执行项目现有 lint/build。

## 验收标准

- [x] 新用户打开应用，无需登录、输入 API Key 或联网请求，即可看到默认实验。
- [x] 拖动参数控件会影响仿真；播放、暂停、单步、重置行为符合预期。
- [x] 高 DPR 屏幕上的 Canvas 清晰；调整窗口尺寸后画面可重绘。
- [x] 切到后台再返回不会因异常大的 dt 导致状态爆炸。
- [x] 模型错误有可见反馈且可恢复；反复进入/退出实验不会叠加动画循环。
- [x] TypeScript 检查、lint 和生产构建通过。
