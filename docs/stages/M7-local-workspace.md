# M7｜本地科研工作区 MVP

**用户价值：**无需账号和后端，即可保存、整理并继续使用自己的实验。

**阶段状态：**待开始  
**依赖：**M1；保存 AI 生成实验和代码版本依赖 M3。  
**PRD 来源：**F6 IndexedDB 本地科研工作区。

## MVP 边界

使用浏览器 IndexedDB 作为唯一本地数据库，保存实验 Schema、必要的代码版本及最近参数状态；同时统一保存用户自有的模型 API Key、第三方 API 站点端点等配置（不写入 localStorage、Cookie 或服务端），提供配置查看、更新与清除。数据只属于当前浏览器存储，不承诺跨设备同步或恢复清除浏览器数据后的记录。

## 交付任务

- [ ] **M7.1 数据模型与版本策略**：定义实验记录 ID、标题、Schema 版本、代码版本、参数快照、收藏状态和更新时间；定义模型配置记录（API Key、第三方 API 站点端点、默认模型）的字段与独立存储分区；设计迁移/不兼容记录处理。
- [ ] **M7.2 IndexedDB 存储层**：封装新增、读取、更新、删除及迁移操作，覆盖实验记录与模型配置两类数据；处理配额不足、不可用和事务失败。
- [ ] **M7.3 自动保存策略**：在生成/应用实验和参数状态变化后保存；避免每一帧动画都写入数据库。
- [ ] **M7.4 工作区列表**：展示最近实验和收藏；支持重命名、收藏/取消收藏、快速切换和删除。
- [ ] **M7.5 恢复与迁移**：页面重新打开后加载记录与模型配置；对旧/未知 Schema 版本给出升级、只读或导出提示，不静默破坏数据。
- [ ] **M7.6 本地数据验证**：覆盖刷新恢复、切换、重命名、收藏、删除、模型配置的保存与清除、存储错误及版本迁移。

## 验收标准

- [ ] 保存的记录在刷新页面后仍存在。
- [ ] 切换记录可恢复该实验的 Schema 和最近参数；支持时恢复对应代码版本。
- [ ] 重命名、收藏、取消收藏和删除均持久化，并有明确操作反馈。
- [ ] 用户 API Key 与第三方 API 站点端点保存在 IndexedDB，界面明确告知仅存于当前浏览器，并支持一键清除。
- [ ] 仿真每帧更新不会导致每帧写库或无界存储增长。
- [ ] IndexedDB 不可用/配额不足时，用户收到清晰提示，当前实验仍可使用。
- [ ] 有数据版本迁移策略和可重复测试。

## 完成定义

同一浏览器内能保存并恢复实验记录，基础整理操作可靠，存储故障不会阻断即时实验。

## 暂不纳入

登录、云同步、团队共享、跨浏览器同步和服务端数据库。
